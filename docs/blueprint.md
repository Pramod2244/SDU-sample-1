# **App Name**: SDUAHDR University

## Core Features:

- Animated Sticky Header: Animated header with transparent to solid background transition on scroll. Includes navigation and call-to-action buttons.
- Fullscreen Hero Video: Autoplay looped background video with a dark overlay. Headline and subheadline text with staggered animations.
- Value Proposition Cards: Animated cards highlighting key value propositions (Whole-Person Education, Career-Focused Learning, Global Perspective) with hover effects and scroll-triggered entrance animations.
- Admissions & Aid Section: Split section with content blocks for Undergraduate Admissions, Graduate Admissions, International Students, and Scholarships & Financial Aid. Parallax image effect and fade-in content on scroll.
- Academics Program Explorer: Responsive grid showcasing Undergraduate Programs, Graduate Programs, and Professional Certificates with hover reveal animations on each program card.
- Campus Life Horizontal Scroller: Horizontal scrolling section featuring topics like Housing & Dining, Student Clubs, Wellness & Safety, and Community Engagement with smooth inertia scrolling.
- News & Events Carousel: News and Events section featuring a prominent news card and a dynamic event list with animated cards and dates.
- About Section with Scroll-Triggered Reveals: An informative About section with Mission & Vision, Values, Leadership, and History, featuring large typography, quote highlights, and editorial layout with scroll-triggered reveals.
- Animated Footer: Clean footer design with contact information, address, social icons, policies, accessibility links, sitemap and subtle animations on scroll.

## Style Guidelines:

- Primary color: Deep Maroon (#800000) to reflect academic identity.
- Background color: Light gray (#F0F0F0) for a modern and clean feel.
- Accent color: Dark Gray (#333333) to provide a sophisticated contrast.
- Headings: 'Playfair', a serif font, providing a stylish, fashionable, high-end feel to headlines.
- Body: 'PT Sans', a sans-serif font, used to ensure the body content is highly readable.
- Use simple, modern icons for program categories and UI elements.
- Component-based, reusable architecture with mobile-first responsive design.
- Smooth scrolling, scroll-based reveal animations, and hover micro-interactions using Framer Motion.
